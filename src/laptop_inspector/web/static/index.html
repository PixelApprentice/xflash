About Aegis Laptop Diagnostics

Aegis (Laptop Buyer Kit v2.0) is an offline-first, open-source laptop diagnostics platform engineered for used hardware buyers, refurbishers, and technicians.

Core Engineering Principles

  • Zero-Trust Offline: Zero telemetry, zero uploads, zero remote script tracking. Evaluates entirely on-device.
  • Transparent Uncertainty: Missing or unsupported metrics are never converted into a fake "100% Pass".
  • Discrepancy Investigation: Non-destructive discrepancy detection without automatic accusations of seller fraud.
  • Safe Buyer Mode: Read-only inspection; no destructive wipes, partition edits, or unapproved firmware modifications.

Dual Execution Modes: Portable vs. Normal

  • ⚡ USB Portable Mode (Zero-Trace): When launched from a USB drive via start-xflash.bat / start-aegis.bat (Windows) or ./run-portable.sh (Linux), all inspection histories and exported reports are written directly to ./aegis_data/ and ./aegis_reports/ on the USB stick. Zero files, registry keys, or temp directories are left on the target laptop.
  • 💻 Normal System Mode: Standard local installation storing records in user application directories (~/.local/share/xflash/).
